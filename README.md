# 🎓 Course Registration System (CLI Binary Engine)

ระบบจัดการข้อมูลนักศึกษา รายวิชา และการลงทะเบียนเรียนแบบ Command Line Interface (CLI)
ประมวลผลข้อมูลผ่านไฟล์ไบนารีชนิด **Fixed-length Record** จำนวน 3 ไฟล์ ด้วย Python `struct` module

---

## 👨‍💻 Project Information

* **Developer:** Thitiwat Thaicharoen (AIGUS__) & Project Team
* **Course:** Computer Programming Project (COMPRO)
* **Architecture:** Fixed-Length Binary Storage, Little-Endian (`<`)
* **Library:** Python Standard Library เท่านั้น (`struct`, `os`, `datetime`)
* **Platform:** Python 3.10+ / Terminal

## 📌 System Features

### 1) 📚 Course Management (`courses.dat`)
- **เพิ่มรายวิชา** — ตรวจสอบทั้ง Course ID ซ้ำ และรหัสวิชาซ้ำก่อนบันทึก
- **แก้ไขรายวิชา (In-Place Update)** — ใช้ `seek()` เขียนทับตำแหน่งเดิม ไม่สร้างไฟล์ใหม่
- **ลบรายวิชา (Soft Delete)** — เปลี่ยน flag `status = 0` คงโครงสร้างไบนารีไว้
- **ดูรายวิชา** — เมนูย่อย 4 แบบ: ดูทั้งหมด / ดูรายการเดียว / กรองตามหมวดวิชา / สถิติสรุป

### 2) 🧑‍🎓 Student Management (`students.dat`)
- เพิ่ม / แก้ไข / ลบ (Soft Delete) / ดูข้อมูล
- **ดูนักศึกษา** — เมนูย่อย 5 แบบ: ทั้งหมด / ตามรหัส 13 หลัก / ตามปีการศึกษา / กรองตามสาขา / สถิติ
- **กฎรหัสนักศึกษา:** ต้องเป็นตัวเลขล้วน **13 หลัก** และ **ห้ามซ้ำ** กับคนอื่นในระบบ

### 3) 📝 Enrollment Management (`enrollments.dat`)
- **ลงทะเบียน** — ตรวจสอบนักศึกษา/วิชามีจริง, วิชายังไม่เต็ม, ไม่ลงซ้ำวิชาเดิม, และไม่เกินเพดานหน่วยกิต
- **เปลี่ยนวิชาที่ลงทะเบียน** — แก้ `course_id` ของรายการเดิมพร้อมตรวจเงื่อนไขใหม่ทั้งหมด
- **ยกเลิกการลงทะเบียน** — Soft Delete (`status = 0`)
- **ดูการลงทะเบียน** — เมนูย่อย 5 แบบ: ทั้งหมด / ตามรหัสนักศึกษา / ตามปีการศึกษา / ตาม Course ID / สถิติ
- **ดูวิชาที่เปิดให้ลงทะเบียน** และ **เพิ่มวิชาสำหรับลงทะเบียน** ได้จากในเมนูนี้โดยตรง

### 4) 👨‍🏫 Instructor (อาจารย์ผู้สอน)
- **เลือกวิชาที่จะสอน** — กำหนด/เปลี่ยนอาจารย์ผู้สอนของรายวิชา
- **ดูรายวิชาแยกตามอาจารย์** — ดูทั้งหมด หรือค้นหาตามชื่ออาจารย์

### 5) 📄 Report Generator (`report.txt`)
รายงานสรุปรวมข้อมูลจากทั้ง 3 ไฟล์ ประกอบด้วย:
- ส่วนหัว: เวลาสร้าง, เวอร์ชัน, Endianness, Encoding, รายชื่อไฟล์
- ตารางรายวิชา / นักศึกษา / การลงทะเบียน (แสดงทั้ง Active และ Deleted)
- สรุปจำนวน Total / Active / Deleted ของแต่ละไฟล์
- **Free Slots** — จำนวน record ที่ถูก soft-delete และพร้อมถูกนำกลับมาใช้ซ้ำ
- สถิติค่าธรรมเนียม (Min/Max/Avg) และจำนวนวิชาแยกตามหมวดหมู่
- **ประวัติการทำงานล่าสุด** 10 รายการ (อ่านจาก `operations.log`)

### 6) 🔒 Safe Exit
เมื่อออกจากโปรแกรม ระบบจะ `fsync()` ไฟล์ไบนารีทั้ง 3 ไฟล์ และสร้างรายงานสรุปอัตโนมัติก่อนปิด

## 🛠️ Data Dictionary

### `students.dat` — **97 ไบต์ / record**

| Field | Format | Size | Description |
| :--- | :---: | :---: | :--- |
| **student_id** | `I` | 4 | ปีการศึกษาที่เข้า (เช่น 67, 68, 69) — **ซ้ำกันได้** |
| **student_code** | `15s` | 15 | รหัสนักศึกษา 13 หลัก (UTF-8, Padded) — **ห้ามซ้ำ** |
| **name** | `50s` | 50 | ชื่อ-สกุล (UTF-8, Padded) |
| **major** | `20s` | 20 | สาขาวิชา (UTF-8, Padded) |
| **year** | `I` | 4 | ชั้นปี |
| **status** | `I` | 4 | `1` = Active, `0` = Deleted |

> **Format String:** `"<I 15s 50s 20s I I"`

### `courses.dat` — **165 ไบต์ / record**

| Field | Format | Size | Description |
| :--- | :---: | :---: | :--- |
| **course_id** | `I` | 4 | รหัสไอดีรายวิชา (เช่น 1001) |
| **code** | `15s` | 15 | รหัสวิชา เช่น CS101 (UTF-8, Padded) |
| **title** | `50s` | 50 | ชื่อรายวิชา (UTF-8, Padded) |
| **category** | `20s` | 20 | หมวดวิชา เช่น Core, GenEd (UTF-8, Padded) |
| **credits** | `I` | 4 | จำนวนหน่วยกิต |
| **fee** | `f` | 4 | ค่าธรรมเนียมรายวิชา (บาท) |
| **status** | `I` | 4 | `1` = Active, `0` = Deleted |
| **is_full** | `I` | 4 | `0` = เปิดรับ, `1` = เต็ม/ปิดรับ |
| **instructor** | `60s` | 60 | ชื่ออาจารย์ผู้สอน (UTF-8, Padded) |

> **Format String:** `"<I 15s 50s 20s I f I I 60s"`
> **สูตรขนาด:** `4 + 15 + 50 + 20 + 4 + 4 + 4 + 4 + 60 = 165 Bytes`

### `enrollments.dat` — **47 ไบต์ / record**

| Field | Format | Size | Description |
| :--- | :---: | :---: | :--- |
| **enroll_id** | `I` | 4 | รหัสไอดีการลงทะเบียน |
| **student_code** | `15s` | 15 | อ้างอิงรหัสนักศึกษา 13 หลักใน `students.dat` |
| **course_id** | `I` | 4 | อ้างอิง `course_id` ใน `courses.dat` |
| **enroll_date** | `20s` | 20 | วันที่ลงทะเบียน (`YYYY-MM-DD HH:MM:SS`) |
| **status** | `I` | 4 | `1` = ลงทะเบียนอยู่, `0` = ยกเลิก |

> **Format String:** `"<I 15s I 20s I"`

## 🔑 เหตุผลการออกแบบที่ควรทราบ

### ทำไมมี ID สองแบบ?
ระบบมีตัวระบุนักศึกษา 2 ตัวที่มีกฎต่างกัน:

| ฟิลด์ | ตัวอย่าง | ซ้ำได้? | ใช้ทำอะไร |
| :--- | :--- | :---: | :--- |
| `student_id` | `69` | ✅ ซ้ำได้ | ปีการศึกษาที่เข้า ใช้จัดกลุ่มนักศึกษารุ่นเดียวกัน |
| `student_code` | `6906022610067` | ❌ ห้ามซ้ำ | รหัสประจำตัวนักศึกษา ใช้เป็นคีย์อ้างอิงจริง |

เพราะ `student_id` ซ้ำกันได้ ระบบจึงใช้ **`student_code` เป็น Foreign Key** ในไฟล์ `enrollments.dat`
เพื่อให้ระบุตัวนักศึกษาได้แม่นยำว่าใครลงทะเบียนวิชาใด

### ทำไมเก็บอาจารย์ไว้ใน `courses.dat` ไม่แยกไฟล์?
โจทย์กำหนดให้ใช้ไฟล์ไบนารีได้ **3 ไฟล์** เท่านั้น จึงออกแบบให้ชื่ออาจารย์ผู้สอนเป็นฟิลด์หนึ่ง
ในตัว record ของรายวิชาแทนการสร้างไฟล์ที่ 4 (ความสัมพันธ์เป็นแบบ 1 วิชา : 1 อาจารย์)

## 📐 Binary Random Access & Free-list

ทุก record ในไฟล์เดียวกันมีขนาดคงที่เท่ากัน จึงคำนวณตำแหน่งเพื่ออ่าน/เขียนทับได้ทันที:

```text
Offset = Record Index × Record Size

[ Record 0 ] -> [ Record 1 ] -> [ Record 2 ] -> ...
                     ▲
                     │ file.seek(1 × RECORD_SIZE) เพื่อเขียนทับ Record 1 ได้ทันที
```

### การจัดการ Free-list (Slot Reuse)
เมื่อลบข้อมูลระบบใช้ **Soft Delete** (เปลี่ยน `status = 0`) โดยไม่ลบ record ออกจากไฟล์จริง
เวลาเพิ่มข้อมูลใหม่ ระบบจะ:

1. วนหา record แรกที่ `status == 0` (ช่องว่างที่ถูกลบไปแล้ว)
2. ถ้าเจอ → `seek()` ไปเขียนทับช่องว่างนั้น **ไฟล์ไม่โตขึ้น**
3. ถ้าไม่เจอช่องว่าง → เขียนต่อท้ายไฟล์ด้วยโหมด `'ab'`

ทำให้พื้นที่ที่ถูกลบถูกนำกลับมาใช้ซ้ำ ไม่ปล่อยให้ไฟล์บวมขึ้นเรื่อยๆ

## 📋 กฎระเบียบที่ระบบบังคับใช้ (Business Rules)

| กฎ | รายละเอียด |
| :--- | :--- |
| รหัสนักศึกษา | ต้องเป็นตัวเลขล้วน 13 หลัก และห้ามซ้ำกับนักศึกษาที่ยัง Active |
| หน่วยกิตสูงสุด | นักศึกษา 1 คนลงทะเบียนรวมกันได้ไม่เกิน **22 หน่วยกิต** |
| ลงทะเบียนซ้ำ | ห้ามลงทะเบียนวิชาเดียวกันซ้ำในขณะที่ยังลงทะเบียนอยู่ |

| รหัสวิชาซ้ำ | ห้ามเพิ่มรายวิชาที่ Course ID หรือรหัสวิชาซ้ำกับวิชาที่ยัง Active |
| อินพุตผิดประเภท | ถ้าป้อนตัวอักษรแทนตัวเลข ระบบจะถามใหม่จนกว่าจะถูกต้อง ไม่ยกเลิกการทำงาน |

## 🚀 How to Run

**รันโปรแกรมหลัก**
```bash
python main.py
```

**เมนูหลัก**
```
1) จัดการรายวิชา (Courses)
2) จัดการนักศึกษา (Students)
3) การลงทะเบียนเรียน (Enrollments)
4) อาจารย์ผู้สอน (Instructor)
5) สร้างรายงานสรุป (Generate Report)
0) ออกจากโปรแกรม (Exit)
```

> เมื่อรันครั้งแรกและยังไม่มี `courses.dat` ระบบจะสร้างวิชาตั้งต้นให้อัตโนมัติ 3 วิชา
> (CS101, GE101, SP101) เพื่อให้ทดสอบการลงทะเบียนได้ทันที

**สร้างชุดข้อมูลทดสอบ (195 records)**
```bash
python generate_test_data.py
```

**รันชุดทดสอบอัตโนมัติ**
```bash
python run_tests.py
```
ผลลัพธ์จะถูกบันทึกไว้ในไฟล์ `test_results.txt`

**แปลงไฟล์ข้อมูลเก่า (เฉพาะกรณีมี `courses.dat` รูปแบบเดิม 105 ไบต์)**
```bash
python migrate_courses.py
```
